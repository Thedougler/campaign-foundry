# Theatre of the mind

This skill writes the Narration the DM speaks or shows to the Players: `[!narration]` boxed text and the Cues on DM-side lines. Spoken Narration works when the table can picture the situation and propose actions after one hearing. The bar is Brennan Lee Mulligan and Matt Mercer at the table (ADR 0029).

## Scope

The caller gives the work as a page and its callout or Cue line, a Session Ledger and its Transcript (or a Transcript alone) for the Previously On, or a Handout to create. Every read and every write this run makes comes from what the caller gave or from a step 2 `flesh-out` pass.

**Read only:**

- the production start-here context required by `AGENTS.md`, then the caller's named pages/files, Session Ledger and Transcript; `wiki/templates/Handout.md` for a requested new Handout
- this SKILL.md, [references/critique.md](references/critique.md) and the recipe **Slots** gives for the slot, in this skill or in the content skill that writes the page: [references/previously-on.md](references/previously-on.md) for the Previously On; for every other slot, its recipe plus the shared rules in [references/recipes.md](references/recipes.md)
- an image only where a page you were given already points at it and the file is readable
- the `## Quotes` section on the page of each NPC who speaks in the block (see **People**)
- three passages from `reference/gm-voice/exemplars.md` for a spoken slot (step 2)

**Write only:**

- the callout's body, or the text between a Cue's `==` marks, on the caller's named pages, title and trigger kept, the rest of each page as it is apart from gate repairs
- facts a step 2 `flesh-out` pass adds to a generic subject page, under that skill's reads and gate
- a new Handout page from the template, only when the caller asks for one, linked only where the caller asked
- mechanical fixes from the page gate's `--fix` on the pages this run writes, a Campaign folder's `index.md` regenerated by `index` after a new Handout (`skill://lint` § Commands), and a rewrite of the flagged text behind every finding the page gate reports
- repo-root `user-config.md`, when the DM corrects returned Narration's wording or rhythm (see **The DM's voice**)
- the DM reply

This task writes Narration, not art or Foundry content.

Done when you can list every file this run will read and every page it will write, and each is on these lists.

## Steps

1. **Find the slot.** Read the type or kind of the caller's page and the callout's title, then find the slot's row in **Slots**. For `Previously on`, read [references/previously-on.md](references/previously-on.md) and follow its sequence instead of steps 2 to 4. For every other slot, read the recipe its row names and the shared rules in [references/recipes.md](references/recipes.md). Done when the slot, its Job/Build/End, its band and its applicable final-check items are identified.
2. **Gather.** Read the caller's page and only the caller-supplied source pages the slot needs for perceivable facts. Links select relevant subjects from that set, not further reading. When a subject's page is still generic, with no signature or too few facts to fill the slot's Build, run `flesh-out` on that page first and gather from the stocked page. Use an image only when the subject page already points at it and the file is readable. Keep source-backed facts and the old block in context, not a scratch file. For a spoken slot, then read three passages from `reference/gm-voice/exemplars.md` whose moment label matches the slot (a scene opening for an Opening, a failed check for a failure Cue), at least one Brennan and one Mercer, and note the slot's exemplar DM in **Slots**. Study how each DM paces a description, where it stops and how it hands the Players a choice, and how each voices an NPC. Write the block in fresh words, per root `AGENTS.md` **Sourcing**. When that file is absent, name it in the DM reply as a missing prerequisite and draft from **Craft**. Done when every candidate detail has a named source, every read stays within the allowed input, and a spoken slot's three passages are read.
3. **Draft.** Take the Party's place and see what they see. Choose the **point**, the one thing the block delivers, and the **anchor**, the feature that shows it. Draft to the recipe's Job/Build/End and length band using the craft below. For a World-page first meeting, follow its ordered construction before moving to Revise. Keep secrets and mechanics in existing DM-side material. Done when every detail is sourced, the actual draft satisfies the recipe's construction checks where given, and the block stops at its End.
4. **Revise.** Read silently, read aloud and retell from memory. Rewrite forced pauses, re-reads and paraphrases. Keep supported counts, timing, uncertainty and names, and preserve exact document payload and quoted table speech. Apply the hard lines and final check below. Then run the critique in [references/critique.md](references/critique.md). Done when the table could follow the block after one hearing, every applicable check is answered with quoted evidence and the critique's re-read is complete.
5. **File.** Replace only the callout body or the Cue's text. The title and the trigger stay as they are. A requested new Handout uses the template. Add links only where the caller asked, then close per `skill://lint` § Commands over every page this run writes. Every finding on those pages is a defect, errors and warnings alike. Rewrite the flagged text and keep its facts. For a `Narration.*`, `narration/*`, `write-good.*` or `proselint.*` finding, use the guideline its rule ID marks beside the craft and hard lines. Then repeat the gate. Skip the gate only when the caller explicitly skips tooling. Run it even when software suites are skipped. Done when the requested callouts are filed, unrelated content is unchanged apart from a step 2 `flesh-out` pass, page-gate mechanical fixes and finding repairs, the page gate reports `ok: 0 findings`, any explicit skip is reported, and the DM reply is ready.

## Craft

- **Spoken camera.** The DM speaks in the second person and the present tense, from inside the Party's view. "You see", "you hear", "you notice", "you feel the cold of the stone through your gloves" and "you know" are the DM's shot boundaries, and "You see…" may open sentence after sentence. The first sentence puts the table inside the situation, with who is doing what and how far it is from the Party. The camera moves from wide to mid and then onto the story object (from the grass plain to the hill fort, and then to black pennants where its crest should fly). Each description ends on a story object, an eye meeting the Party's, or one handoff (Hard line 3).
- **Exemplar.** Each slot takes its exemplar DM from **Slots**. Brennan's way suits social, political, arrival, NPC and lore moments: worn, social nouns (firkins, a crust of bread), a comparison to a place the table already knows, and menace spoken as courtesy, with each joke still giving information. Mercer's way suits spatial and tactical moments. He walks the space in order (behind you, and then ahead for about forty feet), starting with the body at the threshold, and tells wonder as physics. His reveal comes in layers and ends on eye contact.
- **Breath.** The block fills its band in **Slots**, however briefly the DM chats. Run movement and landscape in one long sentence joined by "and" and commas, one thing tumbling into the next, and land each beat on one of the DM's short punchy lines of three to five words (**The DM's voice**): "The egg shatters." A participial trail keeps motion going ("Scattering dust and bone around you."), and a stack of short fragments flashes a reveal. Break any run of same-length sentences (`narration/voice-envelope`).
- **Told.** Each sentence hands off to the next by cause, by motion or by where the eye goes next. Three sentences in a row that each open on a preposition with its place ("In the hold") or a determiner or number with its noun ("The wings", "Its talons", "Two masts") form a list (`narration/fresh-starts`). Open one of the three on "you", a pronoun or a name and its verb ("She banks low"), a connective ("Then", "Still") or a clause, within the slot's length band. Write each sentence so it can be the last one before a player interrupts.
- **Playable.** The table acts on what the description gives: door states, heights, sightlines, counts and spacing, distances, a clock folded into the scene ("the sun's getting low"). Measure what the table will use, in feet, paces or miles ("about twelve feet up on a brass rod", "the road runs north for more than fifty miles"), or against the body (knee-deep, shoulder-high) where that reads faster.
- **Evidence.** A judgement word is a conclusion (`Narration.JudgementWords`). Give what led to it instead: "a bowl of stew skinned over on the table". At most one evaluative adjective rides a noun (`narration/evaluative-stack`). Specificity adjectives such as material, species or shape (an oak table, a wedge-shaped hull) are exempt. Mood shows through bodies, purpose through use, and the past through what it left behind. Dread and wonder are objects, absences and numbers: a cage clanking somewhere about forty feet off, a lantern the dark swallows whole. Give each clue its diegetic cause (one stone worn smoother than the rest, where fingertips have pressed it for years). Hedged perception marks what the characters can't yet confirm: "what looks to be a crystal", "you could swear the stars have shifted". Rules terms stay out of Narration entirely, and the effect the characters perceive takes their place, per root `AGENTS.md` [In-world voice](../../../AGENTS.md#in-world-voice) (`Narration.MechanicalTerms`). A planned misdirection works only by choosing which perceivable facts lead. Every sentence in it is true and perceivable. Use one comparison per block, drawn from the characters' own world or a place the table knows.
- **Speakable.** Each sentence has one clear subject, a strong verb and short clauses: specific nouns, and a direct clause or a new sentence where a chain of relative clauses would otherwise state the same fact (`narration/relative-chain`). The block must still work after one silent read, one verbatim read aloud and a retelling from memory. Colours are one plain word or a comparison. Things go by the stable name a stranger would use, and a person's name enters once the Party knows it. At most three proper names new to the listeners enter one spoken block, each with a page behind it: a name the table already knows is not new, and "invented" never means the Agent may invent one (`narration/invented-names`). Move a surplus introduction to a later callout, a DM note or a Handout rather than dropping a required fact or renaming established Canon. Say the block aloud for tongue-twisters, accidental alliteration, pun names and homophones. Rewrite ambiguous newly authored prose. Keep a Canon name or an exact quoted line as written, and give it an unambiguous lead-in or a DM pronunciation note where the sound still trips (`narration/spoken-word-trap`). A spoken block is one paragraph, the project's chosen form over bullet or nested-visible scripts. Bullets serve the DM-side layers and delivery notes, and a Handout keeps the document's own formatting.
- **The DM's voice.** Brennan and Mercer set the craft in this section and the sound of a spoken block: its camera, breath and register. The DM's own lines in `## Prose voice` of repo-root `user-config.md` season every spoken block with his diction, humour, warmth and handoffs to the players, so it sounds like him without drifting toward his texting register. Follow his line over the exemplars only on what is his alone (his words, his joke shapes, how he builds a player's moment up), never on register or length. When the DM corrects the wording or rhythm of returned Narration, state the correction as a rule and append it there as one dated line. The DM's own lines stay as written. Then apply that rule to the block and every later one.
- **People.** An NPC who speaks gets a want, a physical action and a line in their own diction, identifiable blind, per `npc-design` [craft.md, Voice](../npc-design/references/craft.md#voice) (`Narration.StockTells`). Word count follows power and comfort: the killer gets one courteous line, the comfortable monster talks at length. When the NPC's page has `## Quotes`, read them first and give the new line that person's diction, rhythm, register and habits in fresh words. The speaker and their action lead in, then the complete line, and nothing follows it: no speech tag between or after the quoted words (`narration/dialogue-attribution`). Villain, quest-giver and other NPC plans are never an opening dump. Put later statements in Development, later callouts, Cues or combat rounds, about one round of information at a time. Keep the prose in the DM's natural speaking voice, not a more eloquent narrator.
- **Withhold.** Secrets, true names, mechanics, DCs, closed interiors, contingent responses and hidden routes remain outside Narration. Lore enters only when a player asks or a roll buys it, as an NPC's line or as "here's what you would know". A visible way out stays in the block. Keep existing DM-side material intact. If the old callout contains a fact that cannot be spoken, account for its omission in the DM reply rather than editing other sections.
- **Fresh words.** Take facts from the pages and leave their phrasing: the source's nouns said back in the source's order are an echo (`narration/echo`). Across a block, vary the phrasing only when it adds a detail. Across a Scene, repeat the stable noun for its main anchor about three times, at the Scene's natural beats and within the callouts it already has. Keep each feature's name the same across the DM side. Constants of a Site or Location are stated once at page or section level, and each opening then gives only what differs: repeat what matters now, and state once what is always true. Quote speech already spoken at the table word for word.

## Delivery

How a block meets the table. The spoken items bind material the DM speaks. A Handout keeps its written form.

- **Chunking.** A block is one pass, and it hands play back to the table. Build one situation to the slot's length band and end at its first natural reaction point. Move subsequent beats to a later callout or turn.
- **Audience.** Calibrate emphasis to this table's need for humour, atmosphere, tactical features or mystery without weakening canon, perceivable-only or player agency.
- **Repetition and interruption.** Boxed text replaces conversation only briefly. Re-offer dimensions, exits and counts in DM-side bullets as play asks for them. Optional per-listener delivery distributes the same true facts to the listener who can use them, then invites a first Player to act. Each PC's action stays with their player.
- **Verbal tools.** Put inscriptions, riddles, prophecies and other verbal information the table must reuse into the Handout slot, as reproducible text rather than ephemeral speech. A riddle must work without relying on one language's spelling, sound or pun.

## Hard lines

1. **The Players own their characters.** A PC does, says, decides and feels only what their player declared (`Narration.PcInterior`). Sensation and knowledge are the DM's to give ("you feel the heat on your face", "you know half the watch stood in that yard"). The decision and the emotion stay with the player. Put the cause in the world: "the scream rattles the lantern glass".
2. **Only the perceivable.** The block contains only what the characters can sense or already know. Omniscient narrator, inferred history and judgement words stay out. Misdirection is allowed only by choosing which true perceivable facts lead.
3. **One event, stopped at the reaction point.** A live event stops at the first moment a player would act: the bowstring drawn, the beam groaning. The outcome waits until someone acts. The block may end on one handoff built from this situation. It is a question with the pressure inside it, or an either/or the place offers ("the main gate, or the small door in the east keep?"). A bare "What do you do?" stays the DM's live line. History already established by play may stand, and a multi-beat live event is split across callouts, Cues or turns, never freeze-framed into one opening.
4. **Canon only.** Use only names that have a page, and take each fact from a page, an image or the DM. Where the sources are silent, the block is silent.
5. **Clean prose.** Commas, "and" and full stops join clauses (`Narration.NoEmDash`, `Narration.NoSemicolon`, `Narration.NoColon`). In each sentence the doer comes before an active verb, and the words are plain and fresh (`write-good.*`, `proselint.*`). Keep this skill's craft words (point, anchor, reaction point) out of Narration.

## Final check

Quote the block's own words for each item. Answer every shared item. Answer the branch items only where the selected recipe's Build calls for them (the openings and first-look rules in [references/recipes.md](references/recipes.md)).

- **Slot.** Does it do the recipe's Job, contain its Build and stop at its End?
- **Situation.** Quote the first sentence. Does it put the table inside the situation, who is doing what and where the Party stands? For a physical first look, quote the Party-facing frame required by the recipe.
- **Landing.** Quote the last sentence. Is it a story object, an eye meeting the Party's or one handoff built from this situation, and does the beat before it close on a short sentence?
- **Canon.** Beside each detail in the block, write the page, image or DM line it came from. Any detail with no source comes out.
- **Evidence.** Is any judgement word, mood word, page label or rules term ([In-world voice](../../../AGENTS.md#in-world-voice)) left (`Narration.JudgementWords`, `Narration.MechanicalTerms`)? Quote each clue's diegetic cause.
- **Playable.** Quote the doors, heights, sightlines, counts and distances the table can act on, or state that the slot gives none.
- **Told.** Quote each sentence's first two words, and every run of three list openers that [Craft](#craft) **Told** names, such as `In the tower`, `The wings` and `Two masts`.
- **Speakable.** Check spoken material only, since a Handout keeps its written form and payload. Quote any sentence longer than a breath or chained from relative clauses, any sound that trips the tongue or mishears at the table, and every name new to the listeners (three at most). Confirm the block still works after the silent read, the verbatim read aloud and the retelling from memory. Quote any em dash, semicolon or colon (`Narration.NoEmDash`, `Narration.NoSemicolon`, `Narration.NoColon`).
- **Echo.** Against the old block and the sources already read, quote every shared run of four or more words. Exact document payload and quoted speech are preserved. Rewrite every other echo.
- **Tells.** On a World page's first meeting, quote the tell for each signature ability or hidden property the page lists. Any without one is added.
- **Hard lines.** Do all five hold, every live event stopped at its reaction point and the recipe's End reached?
- **Length.** Name the band and give the count.
- **Better.** When rewriting, account for each old fact as kept, already present in DM-side material or explained in the DM reply. Does every line read aloud as published-grade prose (root `AGENTS.md` **Print grade**) in the DM's own voice, at least as vivid and exact as the old block?

Branch items, where the recipe's Build calls for them:

- **Zoom.** Quote the wide, mid and close shots, and the story object the block ends on.
- **Felt.** One motion, two grounded channels with a nonvisual one where the sources and these PCs' capabilities support them, each routed to the PC who can perceive it?
- **Placement.** Is every feature's position explicit, and are immediate blocking or lethal hazards in the first look? Is a fight-layout block paired with its map or sketch immediately after narration?
- **Delivery.** Can a player interrupt after any sentence, and is each NPC attribution lead-in then line? Are villain and quest-giver plans kept out of the opening, with the key details repeated across the Scene and the first actor named?
- **Shape.** Does each neighbouring area get only a clause unless this is an overlook? Does each comparison stage only one image, and does size ride a measure or a body scale the table can use?

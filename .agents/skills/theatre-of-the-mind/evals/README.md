# Narration evals

Parent preparation, dispatch and review follow `evals/README.md`, the authority for current Shattered Sea sources, protected Runner access and Session lifetime. `run-evals` runs the committed suite; `skill-creator` handles requested paired authoring. Instruction edits alone do not request a description-eval or Prose Benchmark run.

1. **Prepare.** Select active YAML case IDs and prepare current source copies in the owning OS-temp Session. Keep baseline, checks, rubrics and seed explanations private. Done when each selected task has an independent World and immutable public operational descriptor, or a named PREPARATION error.
2. **Request.** Give the Runner the natural DM request verbatim, start-here sources, assigned capabilities/write root and designated output. Narration files through the full check/fix gate with the assigned root/vault/templates; page-filtered gates and extraction dumps are not File completion. Done when the protected Runner has every requested input and permitted File operation without parent-side criteria.
3. **Check and Grade.** The parent verifies sources, checks artifacts and preserves the baseline diff; an independent prose-grader reads the authored Narration and current-run source excerpts for fidelity. Report every requested slot, actual models, quality failures and unavailable evidence. Done when every selected criterion has a verdict or explicit execution/preparation error, and Session storage is closed after Grade/reporting and settled children.

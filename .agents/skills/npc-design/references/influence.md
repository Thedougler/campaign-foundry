# 2024 Influence

Before using this procedure, load `dnd5e-srd-api` and retrieve the current 2024 Influence wording from the 2024 SRD or official Free Rules. Record the source in working notes or relevant page prose. If it cannot be retrieved, report that gap instead of calling a house rule official.

1. **Frame the request.** State what the NPC wants now, what the Party asks, and the cost or threat to the NPC.
2. **Separate states.** Record Attitude as Friendly, Indifferent, or Hostile. Separately record request willingness as Willing, Hesitant, or Unwilling.
3. **Resolve automatic posture.** A request aligned with the NPC's goals or values is automatically Willing. A request that conflicts with an explicit limit, oath, or core value is automatically Unwilling. Use Hesitant only for a genuinely uncertain request.
4. **Set the sourced check.** For Hesitant requests, use the 2024 rule's DC `max(15, the NPC's Intelligence score)`. Apply the rule's advantage or disadvantage for Attitude. Write the roll as `Ability (Skill)` and explain why that truthful approach fits the NPC's want, fear, limit, and contradiction. Conversation, evidence, a favour, a gift, a truthful appeal, Deception, or a credible threat can be valid approaches; none is automatic.
5. **Resolve movement.** Roll only when the outcome is uncertain and a miss changes the situation. State success and miss separately. Success changes willingness, access, terms, or attitude. A miss spends time, trust, leverage, safety, or opportunity. Neither result rewrites beliefs or removes agency.
6. **Name the new position.** State what the NPC now will do, will not do, or needs next, including the cost and the next interruption point.

Do not gate an essential clue behind one Influence check. Give it about three independent routes such as a statement, trace, witness, document, or consequence. A miss can add danger, delay, cost, or uncertainty while leaving a route forward.

Any deviation from the sourced 2024 rule is a declared invention and is not described as official Influence.

# Intent

The skills and templates here come from an earlier project. They record what the DM wants each piece to do, not how to do it: they are unoptimised and were partly edited by weak agents. Read one to learn its intent, then build the v2 from scratch against `CONTEXT.md`, the ADRs and `docs/wiki-layout.md`. Never copy, adapt or cite their text, structure or file references. Delete each one once its v2 exists.

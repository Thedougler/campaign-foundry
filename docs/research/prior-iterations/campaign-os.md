# campaign-os

https://github.com/Thedougler/campaign-os · Claude-Code co-DM llm-wiki for the same Shattered Sea campaign · last activity 2026-08-15 · stack Markdown/Obsidian vault, Rust wiki-cli, Python dndsim, Vale, Quartz

## Summary
Campaign-OS ran the DM's Shattered Sea table (sessions 0–8) as a stateless llm-wiki: typed template pages, a PREP→CAPTURE→INGEST→RECAP→PUBLISH loop, 69 skills, a Rust lint/index engine, and a combat simulator. Superseded by Campaign Foundry, which already re-implements the wiki core (ingest, prep, scene skills, lint, push) more cleanly in omp. Its unique surviving value is the *creative doctrine* — Fronts/clocks, player gravity, beat pressure patterns, prose-voice profiling, writers-room competition — and canon-candidate lore CF's index doesn't yet carry.

## Worth salvaging

- **Fronts & world-update** (`.claude/skills/world-update/SKILL.md`, `references/`) — Factions/NPCs carry `### Front:` clocks (segments, trigger conditions, consequence-at-fill); post-ingest, an agent triages each HOT/WARM/COLD, rolls d20, and proposes ledger lines (`FACT/APPEAR/NEW/QUEST/REVIEW` with file:line citations), stopping hard at a fill for DM confirmation. CF has Threads but no offscreen-advancement engine. Co-opt the clock format into `faction-design`/`npc-design` pages and the advancement ritual into a post-Ingest step; "nothing happened is still something" and the fill-gate are the load-bearing rules.
- **Player gravity** (`vault/campaigns/shattered-sea/player-gravity.md`, `vault/refs/blm-player-gravity.md`) — one canon page listing, per PC, every established pull (goals, gear-lust, grudges) *with session citations*, plus the authority-ladder table mapping each PC to the campaign's theme tiers. Every prepared beat must cite a **Link of Relevance** to it. CF's prep-session/Spotlight would sharpen materially; lands as a Campaign state page `plan-session`/`prep-session` read first.
- **Cold opens** (`.claude/skills/writing-cold-opens/SKILL.md`) — a 20–30-min borrowed-POV prelude before the Hook: five-check ratchet (Orientation→Pressure→Complication→Crisis→Payoff), explicit player-knowledge vs PC-knowledge firewall, fixed trajectory with open outcomes, hard cut into the PCs. CF has no equivalent; adopt as a new skill beside `hook-scene` or an optional Prep scene kind.
- **Writers room, compete mode** (`.claude/skills/campaign-writers-room/SKILL.md`, `references/stances.md`) — N parallel stance-distinct drafts of one prose piece, linted to zero, comparatively ranked, DM picks, optional synthesis wave merging named strengths. Maps almost 1:1 onto CF's Matrix/Judge/Prose-Benchmark machinery — a per-piece creative lever, not a leaderboard. Adopt as a skill reusing `cf bench`-style judging.
- **DM-voice profile & correction capture** (`.claude/skills/writing-style/SKILL.md`, `vault/refs/stories/prose-aesthetic.md`, `banned-patterns.md`, `influences.md`) — researched *moves* from named works (transfer-test: technique, not content), plus a standing rule that any DM prose correction is captured into the profile the same turn. CF's `humanizer` kills AI tells but has no persistent DM voice. Co-opt the four-file profile + capture rule into a skill feeding `theatre-of-the-mind`.
- **Travel/journey design** (`.claude/skills/travel-events/SKILL.md`) — five-slot journey shape (departure cost, landmark, events, toll, arrival-changed), Pointy-Hat TES color palette, events *derived from party threads, never rolled*, spotlight balancing, per-PC travel roles. Directly serves a sea campaign with Vehicles; new skill between `location-design` and `prep-session`.
- **Exemplar corpus + craft-improvement runbook** (`docs/exemplars/*.md`, `vault/refs/runbook-craft-improvement.md`, exemplar-quality-rubric-*.md) — vendored published adventures distilled to markdown with rubrics, and a procedure to recreate an external GM methodology from source and challenge the repo against it. Feeds `theatre-of-the-mind`/`dnd-benchmark` with gradeable gold standards. CF has `docs/research/` but no prose exemplars.
- **dndsim** (`utils/dndsim/CONTEXT.md`, ADRs 0007–0011) — rules-agnostic Monte-Carlo combat engine: lockstep-batched universes, primitives with resolve+expected-value, pluggable policies, importer compiling vault statblocks. CF's `dnd-benchmark` is prose-only; port (code) for Encounter balancing in `cliffhanger-scene`/`climax-scene`, or co-opt the auto-tune loop idea.
- **Gravity metrics** (`utils/wiki-cli/CONTEXT.md` ADR-0051) — three page scores: structural PageRank (typed-frontmatter edges ×3), player gravity (transcript mention counts → active/encountered tiers), agent-reads diagnostic. Would improve CF `query`/QMD context selection and hot-page reporting. The Louvain dynamic organiser conflicts with CF's fixed template layout — take the metrics, skip the organiser.
- **Beat pattern catalogues** (`.claude/skills/writing-cliffhanger-beats/references/cliffhanger-patterns.md` etc.) — named pressure patterns (Chase/Pursuit/Race/Battle/Ambush/Confrontation), escalation ladders of 2–4 state thresholds, four fallout classes (success/complication/setback/bypass), Water test. CF's scene skills exist; port the pattern files as references.
- **Blind-proof gate** (`.claude/skills/campaign-os/SKILL.md` § Validate) — no skill/template change trusted until a fresh cheap model produces correct output *first blind attempt*; failure means the unit still bundles concerns. Complements CF `run-evals` (fixtured) with a lighter per-change check.

CF already covers: beat-type scene skills, ingest/recap/previously-on, lint/QMD, templates, push-to-Foundry, image generation.

## Lore to retell
- **Season architecture & endgame** (`vault/campaigns/shattered-sea/campaign-overview.md`) — four-season authority ladder (local→colonial→false divine: Grung gold caste + Auralis in parallel→true divine: Umberlee); ending is a three-way choice at the Drowned Maw: side with Umberlee (tribute may hold the fissure shut), challenge her, or third path. CF has Auralis and the fissure but not the ladder/endgame.
- **Fronts live at ep-009** (`threads.md`): House Kailani vs House Renzetti duel for Sparhold ("Sparhold's Challenge"); Chain Council "Denial" at Kalowe; The Tangle's "The Below" — a habitat carrack building quietly at Sparhold; Khlysty "The Army, Not the Heir" (Grigori's bindable-power search, noble-heir ascension); "The Dead Lady" taking boats whole as Umberlee's tribute against Delmar's Pearl debt; Aldric Drave's phylactery network; the Tessarine "Magus Dragon's Hoard".
- **Setting texture** (`vault/campaigns/shattered-sea/lore/`, `peoples-of-the-shattered-sea`, `shattered-sea-pantheon`) — Galewall storm belt as the edge of charted homelands; Waveservants as port-infrastructure faith; The Passage's value being that it is written down nowhere.

## Skip
- `co-dm` live-table skill and `record-session-audio`/`transcript` — CF's Agent works only between sessions (ADR-0002).
- `publish-site` Quartz default-deny player site — CF pushes Handouts to Foundry instead.
- `docs/guardrails/` routing kit, `.scratch` issue tracker, Obsidian plugin skills (bases/metabind/leaflet/canvas) — omp skills, CF conventions, and a plain vault supplant them.
- `npc-voice` ElevenLabs dialogue and `battlemap-render` — marked experimental/"back to the drawing board" in FEATURES.md.
- 90-template `owner_skill`/provenance machinery and lint-as-instruction-list (ADR-0064) — CF's `cf check` already owns this space.

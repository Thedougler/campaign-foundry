# Full rules text goes into the Wiki, SRD or not

This is a non-commercial home game, so the Wiki holds full stat blocks, spell text and item text from any source the DM owns, not just the SRD. We rejected referencing non-SRD content by name only: the DM must be able to run a Session from the Wiki alone (ADR 0002), which a name-only reference defeats. Licensing constraints that would apply to a published product don't apply here.

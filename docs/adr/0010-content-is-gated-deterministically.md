# Wiki content is gated deterministically; LLM judges only score skills

Every Wiki page, whoever wrote it, must pass one `check` command whose layers are all mandatory: conformance to its page kind's template (properties and sections), placement per `docs/wiki-layout.md`, required sections, resolving wikilinks and embeds, no orphan pages, markdownlint and remark-lint, cspell with a dictionary built from page names, Harper grammar, Vale prose style (including the ai-tells package), and rules-figure arithmetic in stat blocks. The DM owns the facts and the gate owns the form: the Agent fixes any failure, including in the DM's text, without changing what the text says is true. The gate is the Agent's own completion step, fast and auto-fixing where it can; it is not a blocking git hook, because hooks that stall work cost more than they catch. The gate is a TypeScript CLI built for agents (per the `cli-for-agents` skill) that composes the project's existing tools (markdownlint-cli2, remark and remark-lint, cspell, Harper, Vale, yaml) and writes only the glue and the checks no tool offers, such as template conformance and rules arithmetic. The templates in `wiki/templates/` are the only definition of page shape; the gate derives its rules from them, so there are no schema files to maintain alongside. LLM-judge rubrics appear only in promptfoo skill evals, never as a gate on content, so the gate stays objective and repeatable.

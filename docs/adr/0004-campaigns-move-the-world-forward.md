# Campaigns move the World forward; one active Campaign per World

What happens in a Campaign changes its World directly: if the party burns Thornwick, the Thornwick page says it burned. A later Campaign in the same World starts from that changed World. We rejected treating the World as a frozen baseline with per-Campaign overlays: it would allow parallel Campaigns, but every page read at the table would become "baseline plus overlay." Running two groups in parallel means forking the World.

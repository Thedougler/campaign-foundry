# The Agent is coding agents working this repo

There is no standalone app. The Agent is whichever coding agent (Claude Code, Codex, and so on) the DM runs in this repo, driven by skills for each job (Ingest, Prep, Push, worldbuilding) and by TypeScript scripts for the deterministic parts: page validation, the D&D Beyond pull and building the Push. The DM already works in Obsidian and a terminal, `AGENTS.md` keeps the setup agent-neutral, scripts are tested with vitest, and skills are evaluated by the coding agent itself: it runs each skill in a subagent against a fixture World and grades the result with another, on the machine's existing Claude Code login rather than an eval framework or API key. We rejected an agent-SDK app with its own UI because it would be a whole product to build before any campaign work could happen.

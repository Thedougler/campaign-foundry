# The Wiki is canonical; Foundry is a one-way projection

The Wiki is the single source of truth for everything that exists in both it and Foundry VTT (NPCs, stat blocks, locations, handouts). The Agent pushes from the Wiki to Foundry; it never syncs back. An edit made only in Foundry is treated as throwaway until the DM copies it into the Wiki. We rejected two-way sync because reconciling markdown pages against Foundry's document database is a large, fragile problem, and one direction keeps the Wiki usable offline and at the table on its own.

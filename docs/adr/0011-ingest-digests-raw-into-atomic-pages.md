# Ingest digests Raw into atomic pages; source formatting is discarded

Ingest never preserves a Raw file's structure or formatting, and never files a page that summarises one source. It breaks the material into its atomic units (each NPC, Location, Faction, Item, event, rule and so on), merges each unit into the page of its kind (creating the page if none exists), and writes it to that kind's template, organised and standardised like every other page. A brain-dump covering a city, three NPCs and a feud becomes edits to five or more pages. The `sources` property on each page links back to the archived Raw it came from, so provenance survives without a per-source page. We chose this over the common LLM-wiki habit of one summary page per source because a DM at the table looks things up by what they are, not by where they came from.

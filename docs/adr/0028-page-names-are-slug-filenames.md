# Page filenames are slugs and the title property holds the page's name

The Wiki names pages by display title as filename: `wiki/shattered-sea/NPCs/Nona Black-Jaw.md`. That couples a page's identity to its casing, spacing and punctuation. A filename can't hold a slash, disambiguation forces parenthetical filenames (`Auralis (Patron).md`, `Otar the Foul (Creature).md`), and every consumer that reads a name off a path inherits filename casing.

Decision:

- **A page's filename is its slug**: lowercase, hyphenated, no spaces (`nona-black-jaw.md`, `otar-the-foul-creature.md`, `auralis-patron.md`). A slug is stable and path-safe. It is not the page's name.
- **The `title` frontmatter property holds the page's name**: `title: Nona Black-Jaw`. The `title` of a templated page is never blank, and the fixed files have titles too (`hot.md` is titled `Hot`). Fixed and generated files keep their established filenames (`hot.md`, `campaign-config.md`, `story-so-far.md`, `index.md`, `log.md`).
- **Links target the slug and show the title**: `[[nona-black-jaw|Nona Black-Jaw]]`, `[[nona-black-jaw#Play|Nona Black-Jaw]]`, `![[otar-the-foul-creature#Statblock|Otar the Foul (Creature)]]`. A link that shows its own text keeps it on the slug: `[[nona-black-jaw|the Black-Jaw]]`. Title and aliases still resolve a link written by name, and `cf rename` rewrites it to the slug form. The prose checks treat a shown label that exactly matches a known title or alias as a page name, as they did a bare name link, and read any other label as prose.
- **Code reads names from the page, never the filename.** Name resolution (`cf find`, link checks, orphan checks), `cf index`, log page lists, Backup page titles, stub generation and eval fixtures all read `title` (falling back to aliases). Filename parsing of names is removed, not adapted.
- **`cf rename` migrates and maintains.** It moves a page to a new slug and sets its `title`. Across the vault, every wikilink and embed that pointed at the old name becomes `[[slug|Title]]`, keeping custom displayed text, headings, block references and the embed marker. The bulk migration of the Shattered Sea vault is one `cf rename` run per page.
- **The parenthetical convention for Creature twins and patrons leaves filenames and stays in titles.** Where an NPC and its Creature share a name, the Creature's `title` keeps its distinguishing bracket (`title: Otar the Foul (Creature)` on slug `otar-the-foul-creature`), so a title may hold parentheses while a filename never needs to.

Consequences: filenames stop being prose. A retitle that keeps the slug leaves every link target intact. One property that every template requires holds the title a Player sees. The migration runs only after the reveal backfill and test rework, so no test pins a filename-based name.

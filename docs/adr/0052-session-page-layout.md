# Session pages are table-ready layouts

Amends [ADR 0029](0029-exemplar-dms-set-the-narration-bar.md) for Cue styling.

The DM runs each Session from its Prep and Scene pages in Obsidian's reading view. Screenshots of Session 13's seven pages in October 2026 showed the slug as the page title, every section as one long single-column list, a gold underline on every wrapped line of every Cue, a Statblock embed showing its owner page's heading and border in one narrow column, `Hands to` links wrapping onto three lines, and no image on any Scene. On 2026-10-15 the DM approved a layout that makes Session 13 the standard for every Session page.

Decision:

- **Opt-in by `cssclasses`.** Each Scene page sets `cssclasses: [cf-scene, cf-<kind>]` and Prep sets `cssclasses: [cf-prep]`, as their templates give them. `wiki/.obsidian/snippets/session-pages.css` styles only pages with those classes. Every other page shows the theme alone. The kind class draws a kind badge above the title and sets the accent colour of the page's cards. The vault shows properties in source mode only, so the classes are the one property the layout reads.
- **Block-level hooks only.** Reading view removes off-screen blocks from the DOM, so a selector that reaches from a block back to its section's `##` heading breaks as the DM scrolls. The stylesheet hooks onto the block itself, by a callout's type or an embed's `src`, and by a heading's own `data-heading` or the page's `cssclasses`.
- **Three layout callouts.** `[!cast]` lists the Scene's on-stage NPCs and Creatures in the lede as portrait cards, each item a reused portrait embed with the page link as its caption. `[!tiles]` renders a bold-led list as a grid of cards: a Scene's Angles and each PC's first action, and Prep's Scene Chart notes (a storyboard led by each Scene's scene-setter) and Spotlights. `[!checks]` renders one card per roll, with one nested item per result: `- **Success.** ==…==`. Each is DM-side and contains one untitled list. A `>` line is left blank between its header and the list, as markdownlint's MD032 requires. The Scene and Prep templates place them, and `docs/wiki-layout.md` **Callouts** states the rule.
- **The gate reads layout callouts as DM-side prose.** The repeated-sentence check covers `[!cast]`, `[!tiles]` and `[!checks]`, and only `[!narration]` is exempt from it. A nested bold result label inside `[!checks]` (`- **Success.** ==…==`) gives the clean Cue trigger `Success`.
- **The gate repairs toward the layout.** `cfcli check --fix` fills a missing frontmatter key with its template's own value. A missing `cssclasses` gets the page's opt-in classes, and a key the template leaves blank is added blank. The fix hint for a missing `[!cast]`, `[!tiles]` or `[!checks]` callout shows the list format: the header, a blank `>` line and a bold-led item.
- **ITS Theme is the vault theme.** ITS Theme with Style Settings supplies heading, table, statblock and body type, and `session-pages.css` layers on it. Front Matter Title shows each page's `title` in place of its slug, and Pixel Banner's image-select flag is off.
- **No page uses the Columns plugin.** It is still installed. It would add a second layout syntax for nothing the three callouts can't do.
- **Cues are tinted, without an underline.** `wiki/.obsidian/snippets/callouts.css` styles every Cue in the vault as italic text on the Narration gold tint. A rule under every wrapped line turned a run of Cues into stripes, so Cues have no underline.
- **Short `Hands to` links.** An Outcomes row links the receiving Scene under its short title, `[[session-13-the-pantry\|The Pantry]]`, which fits on one line.

Consequences: the five `wiki/templates/scene-*.md` files and `wiki/templates/Prep.md` gain `cssclasses` and the layout callouts. `docs/agents/scene-pages.md` § Page format gives the `[!checks]` format and the short `Hands to` alias, and `.omp/skills/visuals/references/placement.md` gives the `[!cast]` strip and the Prep storyboard as reused-image slots. Push sends the page Markdown to Foundry, and the stylesheet applies only in Obsidian. Session 13's pages move to the new layout as its first example. Older Session pages now report `missing-key cssclasses` and the new required callouts, and they migrate when touched (root `AGENTS.md` **Fix on touch**).
